# Contributing to NAPT

## How to contribute

### Feature ideas

1. **Check the [roadmap](roadmap.md)** for planned work
2. **Open a GitHub Discussion** - Share your idea and get feedback
3. **Or open a GitHub Issue** - For more structured feature requests

When suggesting features, please include:

- What problem it solves
- How you envision it working
- Any examples or use cases

### Feedback

- **Questions about using NAPT** - Open a GitHub Discussion
- **Issues or problems** - Open a GitHub Issue

## Code contributions

NAPT does not accept code contributions before 1.0, because recipes,
configuration, and internals still change in breaking ways.
To contribute code later, start a GitHub Discussion.
